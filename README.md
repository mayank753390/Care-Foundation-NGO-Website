# 🌍 Care Foundation NGO Website

> Empowering communities through technology — a modern NGO platform built to showcase initiatives, drive engagement, and support social causes.

---

## 🚀 Project Overview

The **Care Foundation NGO Website** is a dynamic and scalable web application developed using **Django**.
It is designed to provide a digital presence for NGOs, enabling them to highlight their mission, showcase ongoing projects, and encourage community participation.

This project demonstrates strong backend development, clean UI design, and structured project architecture.

---

## ✨ Key Features

* 🌐 **Dynamic Website using Django Framework**
* 🏠 Interactive Home Page with NGO Overview
* 💖 Dedicated Charity & Donation Sections
* 📄 Informational Pages (About, Services, Contact)
* 🎨 Clean & Responsive UI (HTML, CSS, Bootstrap)
* ⚙️ Scalable Backend Architecture
* 📁 Well-structured Django project layout

## ⚙️ Installation Guide

### 1️⃣ Clone Repository

```bash
git clone https://github.com/mayank753390/Care-Foundation-NGO-Website.git
```

### 2️⃣ Move to Project Directory

```bash
cd Care-Foundation-NGO-Website
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run Server

```bash
python manage.py runserver
```

### 5️⃣ Open in Browser

```
http://127.0.0.1:8000/
```
